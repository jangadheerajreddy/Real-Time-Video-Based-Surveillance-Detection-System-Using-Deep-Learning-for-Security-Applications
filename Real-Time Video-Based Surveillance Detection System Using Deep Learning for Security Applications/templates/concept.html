📘 Concept Overview

Real-Time Video-Based Surveillance Detection System Using Deep Learning for Security Applications used to identify **dangerous, unusual, or harmful human behaviors** in real-time. Our system combines **Motion Analysis + YOLO Deep Learning Model** to detect:

  • 🤕 Falling / slipping
  • 🧍 Sudden collapse
  • ⚡ Violent abnormal movement
  • 🧎 Unusual body posture

📡 How The System Works

✔ Background Subtraction finds sudden body movement ✔ YOLO identifies humans accurately ✔ Motion + YOLO combined → detects abnormal posture ✔ Alerts by sound alarm 🔔

💡 Suggestions

  • 💡 Ensure proper lighting
  • 🎥 Camera must capture full body
  • 🚫 Avoid obstacles & blockages
